# Panduan Cloudflare

Paket [cloudflare-panduan-lengkap](cloudflare-panduan-lengkap/SKILL.md) berisi instruksi Markdown berbahasa Indonesia untuk memahami dan memandu pekerjaan Cloudflare.

Topiknya mencakup Workers, Pages, Wrangler, D1, KV, R2, Durable Objects, Queues, Workflows, bot Telegram, AI, domain, keamanan, biaya, observability dan pemulihan data.

Baca [cara memakai](cloudflare-panduan-lengkap/references/mulai-dan-instalasi.md) dan [privasi serta batas paket](cloudflare-panduan-lengkap/references/privasi-dan-batas-skill.md). Tidak ada kode, konfigurasi akun, script, installer atau workflow yang perlu dijalankan. Pemasangan dokumen tidak memberi akses Cloudflare.

Untuk instruksi terminal OpenCode dan skill frontend, lihat [repo skill-agentic](https://github.com/abdullahazwar/skill-agentic).
