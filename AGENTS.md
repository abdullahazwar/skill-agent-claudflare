# Aturan repo panduan Cloudflare

Repo ini hanya berisi instruksi Markdown. Mulai dari [SKILL.md](cloudflare-panduan-lengkap/SKILL.md) dan baca referensi terkait.

Pertahankan seluruh file distribusi sebagai .md. Jangan menambahkan kode, script, installer, config, workflow, SQL, environment file atau template aplikasi. Metadata nama/deskripsi skill bukan konfigurasi akun.

Jangan menerbitkan credential, Account ID, Zone ID, resource ID, hostname pribadi, endpoint privat atau data pelanggan. Membuat panduan tidak memberi izin login, mengubah akun/DNS/billing atau deploy aplikasi.

Tinjau frontmatter, tautan, keutuhan instruksi dan data sensitif sebelum commit/push. Hormati perubahan pengguna dan verifikasi hasil remote. Jangan force-push atau menganggap commit penghapusan menghapus riwayat lama.
